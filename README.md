# Gearbox

Low-latency decision engine: schema-checked rules, decision tables, decision graphs, JSON transforms (Expr), segments, gates, experiments and AI steps, evaluated by a Go sidecar next to every service. Apps call it over gRPC on a Unix socket.

Start with [CONTRACTS.md](CONTRACTS.md) and [AGENTS.md](AGENTS.md). Docs are in [docs/](docs/).
